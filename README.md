# SolarSaver

Демонстрационное приложение для Windows, которое в наглядном графическом виде показывает, сколько электроэнергии можно сэкономить, используя солнечную батарею и аккумулятор вместо питания от общей сети.

## О проекте

Приложение моделирует работу солнечной панели, аккумулятора и потребителя (лампочки) в течение сменяющихся суток. Пользователь может:
- задавать номинальную мощность панели, ёмкость аккумулятора и мощность лампочки;
- включать и отключать солнечную панель и аккумулятор перед запуском симуляции;
- задавать вероятность дождливых дней;
- управлять скоростью течения игрового времени.

В процессе симуляции в реальном времени отображаются:
- текущее время и номер дня;
- выработка панели и потребление лампочки;
- уровень заряда аккумулятора;
- количество сэкономленной энергии и её доля в процентах;
- суммарное потребление лампочки.
